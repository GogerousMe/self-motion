# MATLAB 黑白光栅：方向、静态和多速度校准

本目录从公式重新生成刺激，不读取已有 DAT，不依赖 Python 或原 VisualStimulus 类。使用 MATLAB R2023b 和基础函数即可。

在 MATLAB 中切换到 `D:\A_Gorger\program\MSTD\code`，运行：

```matlab
addpath('matlab');
result = generate_bw_grating_suite('outputs/matlab_bw_grating_01');
```

输出目录必须不存在。重新生成请使用新目录名，避免覆盖已有采集输入。

默认输出 40 个 DAT：

| 子目录 | 速度（像素/帧） | 条件数 |
|---|---:|---:|
| `speed_1p5` | 1.5，基线 | 8 |
| `speed_0p5` | 0.5 | 8 |
| `speed_1` | 1 | 8 |
| `speed_2` | 2 | 8 |
| `static` | 0，配对静态光栅 | 8 |

每段 80×80、单通道、80 帧，每帧 50 ms，共 4000 ms。前 20 帧为分析时排除的初始预热段，仍须全部输入 V1；不另加空白帧。1.5 像素/帧相当于 30 像素/秒。

方向采用项目的图像坐标：0°右、45°右下、90°下、135°左下、180°左、225°左上、270°上、315°右上。角度表示条纹法线的运动方向；条纹自身垂直于运动方向。若与原 MATLAB GratingStim 角度比较，使用 `theta_project = mod(-theta_original,360)`。

默认完整空间周期 12 像素，沿条纹法线约 6 像素白、6 像素黑。像素严格取 0 或 255，没有插值灰度。斜条纹的边缘会呈阶梯状；亚像素运动通过连续更新解析相位、再二值采样实现，不要求每帧整像素平移。方波包含高次谐波，不能把它当作原正弦光栅的等价替换；这里是新的黑白光栅实验条件。速度检查针对基频的时间混叠，高次谐波和像素采样仍可影响模型响应，需要真实 V1 校准。

每个静态条件重复相应运动条件的第一帧，所有速度共享同一初始相位。静态清单中运动方向为 null，不参与胜出方向误差验收。八份静态输入用于逐条件配对，不代表八种可区分的静态运动方向；相反方向的静态条纹可能相同或黑白相位不同。

## 自定义

```matlab
result = generate_bw_grating_suite('outputs/matlab_bw_grating_02', ...
    'Size', [80 80], ...
    'Frames', 80, ...
    'FrameMs', 50, ...
    'WarmupFrames', 20, ...
    'PeriodPx', 12, ...
    'Speeds', [1.5 0.5 1 2], ...
    'PhaseCycles', 0, ...
    'PreviewGif', true);
```

`Speeds` 单位为像素/帧；保持不变而改变 FrameMs 会改变实际像素/秒。总 DAT 数为 `8 × (不同正速度数量 + 1)`。GIF 仅为列表中第一个速度生成；PNG 为每个条件的第一帧，`directions_first_frame.png` 从左到右为 0:45:315。GIF 用于查看，真实仿真以 DAT 和清单记录的帧时长为准。

## DAT 和采集

DAT 使用 VisualStimulus v1 的 25 字节小端文件头：int32 签名 293390619、float32 版本 1、int32 光栅类型 0、uint8 通道数 1、int32 宽/高/帧数；随后是按帧、按行排列的 uint8 像素。写入时转置数组以匹配 C++ 行顺序，不额外 flipud。脚本写完后逐像素读回校验，并记录 SHA256。

每个速度子目录有独立方向校准 manifest；静态清单使用独立 schema；根清单汇总全部条件。每个 DAT 独立启动/重置 V1，单段内部保持时间历史；完整输入 80 帧。`spikes: null` 是未来采集结果位置，不是已经生成了 V1 响应。输入 DAT 与输出 SpikeMonitor DAT 格式不同。

本套只覆盖黑白光栅方向、静态及速度校准，不代替随机纹理方向条件，也不包含三维前进、转弯或动态物体刺激。黑白光栅具有孔径歧义，应按光栅条件解释其校准结果。
