# 两篇运动视觉论文的引入路线与开发交接

日期：2026-10-28（Asia/Shanghai）  
状态：研究与开发路线，不表示下述增强已经实现或通过实验。  
适用范围：当前 Python V1–MT–MSTd 项目。本文供开发 agent 分阶段实施，用户据此把握研究方向。

## 1. 总体决策

**主线：完成 Python V1 迁移与局部方向验证，建立纯平移自运动基线，再根据具体失败原因引入论文机制。**

现在吸收两篇论文的实验设计、分层诊断和表征保留方法；暂不同时引入新 V1、速度解码、图网络、高阶通路和新 MSTd。

“夯实基础”有明确终点：

1. 能解释 Python V1 与固定 C++/CUDA 参考的数值和时序关系。
2. V1→MT 在规定刺激范围内提供可验证的方向证据，静态误报和切换延迟可测。
3. 用该证据建立简单场景下的平移航向基线。

达到上述条件后继续自运动研究，不等待通用光流、所有孔径问题或复杂材质问题全部解决。纯平移航向基线不以完整速度估计为前提。

开发采用两条可并行的路径：

```text
实际图像 → Python V1 迁移对照 → MT 方向验证 ──┐
                                           ├→ 纯平移端到端基线
已知相机运动 → 理想方向证据 → MSTd 独立验证 ─┘
                                              ↓
                           干扰诊断 → 单项增强 → 同输入对照
                                              ↓
                          后退／旋转／曲线参数 → 位姿约束
```

理想输入只用于隔离后端问题，不替代实际图像端到端的结果。

## 2. 项目目标与论文定位

### 2.1 项目任务优先级

1. 当前任务：从图像经 V1、MT、MSTd 估计纯平移航向，输出有效性、群体活动和可靠性特征。
2. 后续任务：动态干扰下的稳定性与跟踪，后退、旋转、平移加旋转、曲率及视线偏角。
3. 更后续任务：与几何、尺度来源及必要传感器约束结合，研究相对位姿和 SLAM 接口。

主指标是自运动任务表现。局部运动指标用于解释原因，不以热图更漂亮、光流更平滑或人类一致性更高替代任务验收。

### 2.2 两篇论文分别贡献什么

| 参考 | 可借鉴的机制 | 在项目中的角色 | 不构成的证明 |
| --- | --- | --- | --- |
| Solari 等，2015，FFV1MT | 运动能量、MT 汇聚、速度群体解码、多尺度、运动边界处理 | MT 表征与真实视频适用范围的参考；局部运动诊断及可选增强 | 已解决 MSTd 航向、曲率、尺度或 SLAM |
| Sun 等，2025 年 1 月 arXiv v1，多阶运动模型 | 可学习运动能量、基于特征的运动图、循环整合、双通路、材质控制训练 | 自适应运动整合与复杂光学环境的扩展参考 | 图网络等于生物连接；运动分组自动等于动态物体识别；已改善自运动精度 |

论文来源：

- [2015 年论文 PDF](../../参考文献/What%20can%20we%20expect%20from%20a%20V1-MT%20feedforward%20architecture%20for%20optical%20flow%20estimation.pdf)，重点为第 2–3 节、图 3、图 6、图 11–12。
- [2025 年论文 PDF](../../参考文献/Machine%20Learning%20Modeling%20for%20Multi-order%20Human%20Visual%20Motion%20Perception.pdf)，PDF 内标题为 *Machine Learning Modeling for Multi-order Human Visual Motion Processing*；重点为第 2.2–2.4、4.1–4.3 节及表 1。

2015 年模型的滤波器与当前 MotionEnergy 并不逐式相同。2025 年模型经过监督训练，不能把任意注意力模块或邻域平均称为该论文复现。本文提出的简化机制统一标注为“论文启发的项目变体”。

2025 年论文对材质与二阶运动的结论属于特定模型和数据上的实验支持；人类二阶运动实验有 3 名参与者，部分自然扰动刺激并非纯二阶。它不证明本项目必然需要高阶通路。

### 3.1 必须保持的语义

- 28 个原始滤波器通道不是 28 个均匀运动方向；84 是 28×3，不是 84 种 MSTd 模板。
- 三个通道块不自动代表三个有效尺度，更不自动代表三个已标定速度。
- 当前 MT 向量是方向证据，不能因字段名含 `vx/vy` 就解释为 px/frame、px/s 或 m/s。
- 只有经明确转换的响应才可标注 Hz；归一化活动是无量纲的。
- 分清连续响应、脉冲采样、时间窗计数、方向投影与整流，不做重复投影或重复单位换算。
- 独立序列重置状态；连续运动变化保留历史。明确图像时间、证据可用时间和估计所对应时间。
- 相机坐标下的平移航向不是 yaw 姿态。固定朝向下的左右偏平移不是转弯。

### 3.2 迁移与改进分别记录

保留一个与选定源实现兼容的基线配置。源代码中的特殊增益、边界补偿、历史顺序和尺度行为，先记录并对照。

当前 `v1.py` 明确保留源中的 `scale > 4` 条件，并注明三个块共享基底。开发 agent 应核对固定源与实际输出，不能凭输出维度宣称存在三个不同尺度。若该行为需要修正，在基线核对后另设变体；数值迁移通过不等于其多尺度功能符合设计期望。

功能修正、参数重新设计或论文滤波器替换必须使用独立配置和模型标识，不掩盖迁移差异。旧 CARLsim 工程及已成功实验的输入、配置与结果保留为参考。

## 5. P0：完成 Python V1 统一与迁移验收

### 5.1 实施方法

1. 固定已确认的源配置、输入、投影、时间间隔和处理分辨率，记录版本及哈希。
2. 使用现有独立 C++ 导出路径保存泊松采样之前的 84 通道浮点响应。先短序列，不必重建整个 CARLsim 网络或处理长脉冲文件。
3. 同一输入运行 Python NumPy；分别比较逐帧、逐通道、内部区域和边界的误差。
4. 若最终使用 GPU，追加 PyTorch CPU/CUDA 对照。Python 两后端相同不能替代独立 C++ 对照。
5. 冻结方向投影和 MT 参数，比较投影、池化与归一化结果，必要时对照参考版与张量版后端。
6. 记录连续路径与历史脉冲路径的区别；需要比较后者时使用多随机运行的统计量，而非要求某一次脉冲实现逐点相同。

有符号投影后的整流和后续归一化均为非线性。去掉采样不能直接推断下游期望输出完全不变。

### 5.2 验收与输出

- 输出原始响应 RMSE、最大绝对误差、相对误差、失败值比例及逐通道／逐帧曲线。
- 使用已有比较工具；浮点容差依据参考量级和运算误差确定并记录，不为通过而事后放宽。
- 不通过自动拟合增益、镜像或任意移动时间曲线掩盖迁移错误。
- 记录初始化、V1、投影／MT、MSTd、读写的耗时；GPU 计时同步完成后统计。
- 形成迁移报告，标明实际执行设备与尚未完成的外部验证。

已有执行说明见 [PYTHON_V1_SERVER.md](PYTHON_V1_SERVER.md)。缺少实际 C++ 捕获时可继续工具与功能检查，但迁移等价状态保留为未验证。

## 6. P1：把论文的验证方法立即加入

### 6.1 最小实验集合

| 刺激 | 控制变量 | 要回答的问题 |
| --- | --- | --- |
| 八方向平移随机纹理、光栅 | 相同速度、尺寸、ROI、时间窗 | 通道与坐标是否正确，纹理与光栅是否给出一致结论 |
| 静态纹理、黑场、运动后停止 | 保留历史状态 | 是否误报运动，残留多久 |
| 无复位连续方向切换 | 保持同一纹理位置状态 | 能否跟踪变化，延迟与残留是否合理 |
| 多速度与多空间频率 | 分别改变一项，其余保持 | 前端可用范围和混叠／失效位置 |
| 同方向平移、不同纹理朝向 | 固定完整二维运动 | 估计是否随纹理方向产生系统偏差 |
| 不同长度移动线段 | 固定速度及池化参数 | 端点与有效感受野如何影响局部歧义 |
| 交叉光栅、角点或二维纹理 | 明确几何与整体运动真值 | 是否出现超出单分量响应的整合能力 |

无限单一光栅存在不可辨识分量，不对其要求唯一真实二维速度。用于诊断的孔径刺激不全部作为进入 P2 的硬门槛；基础编码和时序错误才是必须先解决的问题。

复用已有纹理、静态、连续切换与自运动刺激，见 [NEXT_STIMULUS_SEQUENCES.md](NEXT_STIMULUS_SEQUENCES.md)，避免重新生成语义不同却同名的数据。

### 6.2 诊断输出

保存原始通道或短片段诊断、投影率、池化率、归一化活动、局部方向向量、有效性及时间戳。局部方向用环形误差，零证据时方向无定义，不强行赋零度。

已知完整二维运动时比较方向误差及覆盖率；未校准速度前不计算伪速度 EPE。需要时提供边缘附近、纹理内部、弱纹理等分区统计。

现有八方向工程筛查可以沿用，但不能单独视为全部验收。正式阈值在开发数据上确定，在独立测试前冻结；缺少阈值不妨碍先完成统计、采集与基线报告。

## 7. P2：尽早完成纯平移自运动闭环

### 7.1 执行顺序

1. 用解析相机运动产生理想方向证据，独立验证模板坐标、角度映射和动力学。
2. 固定相同场景与参数，改为实际图像 → Python V1 → MT → MSTd。
3. 优先静止、点云正前进、地面正前进、固定朝向下左右偏移平移；再增加模板网格外角度和独立场景种子。
4. 先比较瞬时模板匹配与当前时间竞争，再加入合理调参的普通指数平滑，防止把平滑或迟钝误认为竞争优势。

### 7.2 核心指标

- 航向 MAE、有符号偏差、P95、稳态波动。
- 有定义帧的有效覆盖率，静止时误报有效率。
- 启动、真实航向变化的跟踪延迟，停止后的消退时间。
- 逐帧模板分数、群体活动、证据、边界模板占用情况。

误差必须和覆盖率同时报告，不通过拒绝大量困难帧制造准确性改善。静止及纯旋转时平移航向无定义。

在开发场景确定阈值后冻结，使用独立场景／轨迹评价。将此版本保存为后续所有增强的任务基线。

## 8. P3：优先实施的论文启发增强

本阶段先制造可定位的困难，再引入相应机制。每个变体默认关闭，不覆盖 P2 基线。

### 8.1 M1：高斯局部池化

**何时加入：** P2 已有基线，或 P1 明确发现方窗池化对结构和方向有不利影响。

**加入位置：** 当前每方向投影率之后、方向归一化之前；替代方窗空间平均，保留其余计算。

**方法：** 对各方向图分别做非负、归一化的高斯加权。明确图像边界截断和有效权重归一化。先使用与方窗相近的有效感受野，再在开发集比较少量固定支持范围，避免把核类型与感受野变化混淆。

**对照：** 原方窗、高斯、必要时半径为零的诊断条件。评价局部方向、边界混合、最终航向、延迟和耗时。

### 8.2 M2：保边界池化

**何时加入：** 运动物体／背景边界处出现局部混合，并且混合影响下游，或局部问题本身需研究。

**方法：** 起步用空间距离与当前图像亮度相似性决定权重，可示意为：

```text
w(p,q) = exp(-||p-q||² / (2σx²)) × exp(-|I(p)-I(q)|² / (2σI²))
Rout[d,p] = Σq w(p,q) Rin[d,q] / Σq w(p,q)
```

这是受论文启发的项目变体，不等价于 2015 年在 MT 响应图上的完整 TF 实现。若再加入响应相似性，单独标记变体并说明特征、归一化和计算位置。

**控制：** 亮度边界不等于运动边界；加入“同亮度不同运动”和“不同纹理但同一运动”条件。只使用当前及历史图像，不使用真值掩膜。无支持区域保留无效，不把填补后的响应视为新的独立观测。

### 8.3 M3：运动特征驱动的自适应池化

**何时加入：** 固定空间核或亮度引导仍无法适应遮挡与不同运动区域，且有实验依据。

**方法：** 在受限邻域内，结合空间约束与运动特征相似性构建权重；明确使用原始滤波器特征、方向活动或其他表征。先做无学习／少参数版本，保存权重诊断。

同一物体边缘可能产生不同分量方向，同一自运动背景的流场也随位置和深度变化。禁止简单设定“方向相同才连接”，并把它当作运动分组已解决。

**验收：** 与方窗、高斯及亮度引导进行同输入对照，同时检查相干运动是否被错误割裂、独立运动是否被错误合并。

### 8.4 与 MSTd 时间竞争分开比较

先固定 MSTd 比较 MT 变体；再固定 MT 比较瞬时匹配、普通平滑和竞争。资源允许时做“池化类型 × 时间机制”交叉对照，区分两者的独立贡献与交互。

加入独立运动物体、匹配面积遮挡、弱纹理、噪声和真实航向变化。报告干扰带来的额外误差、恢复时间及真实变化延迟，不只展示恒定航向下平稳的曲线。

运动图或分组结果不能自动决定哪一组是静态背景。若用于 MSTd 权重，需结合自运动几何／时间一致性，另立实验；仿真真值掩膜只能作为明确标注的上界诊断。

## 9. P4：多尺度、速度与一般自运动的加入方式

### 9.1 M4：保留并核验尺度信息

**何时加入：** 原始尺度行为已核实，速度／纹理频率扫描显示覆盖不足，或尺度汇总引入可重复偏差。

1. 先分别输出每个尺度的投影和方向表现，再比较现有汇总。
2. 若源兼容配置三个块没有实际尺度差异，独立建立真正的多尺度变体，明确下采样、空间／时间滤波和边界。
3. 比较固定权重与基于可观测证据的融合；测试标签不能选择逐帧最佳尺度。
4. 单纯多尺度响应融合与 2015 年金字塔粗到细 warping 是不同机制，分别命名。
5. 仅在大位移需求明确时增加粗到细残差估计；规范坐标、向量缩放、图像内参及边界插值，并单独验证对齐误差。

### 9.2 M5：经标定的速度通道与解码

**何时加入：** 多速度方向性能不足，或旋转混合、位移等任务确实需要幅值信息。它不是纯平移航向基线的前置条件。

1. 扫描方向、图像速度和空间频率，绘制各通道调谐；不能把更高放电率直接等同于更快速度。
2. 有证据支持时增加显式速度维，拟议形状为 `[t, speed, direction, y, x]`，附速度单位与标定条件。
3. 保留未归一化响应、归一化活动和方向一致性，分清强度、可靠性与速度。
4. 比较可解释的标定读出／线性读出，必要时再使用小网络。论文中的固定速度加权不能不经适配直接套到现有 28 通道。
5. 只有输出量经验证为 px/frame 或 px/s 后才计算速度 EPE；米制速度仍需尺度来源。
6. 方向证据与速度场使用不同语义字段／接口，旧 MSTd 接口保持可用，禁止静默替换。

### 9.3 自运动后端继续推进

依次加入收缩、纯 yaw、平移加旋转以及曲线路径；需要时扩展模式模板与参数读出。先验证可区分性，再研究连续参数。

图像中心圆周旋转更接近 roll，不直接代表车辆 yaw；螺旋模板不直接等于左／右转。曲率与米制位移的尺度假设必须显式记录。速度通道是否必需，由任务实验决定，不把所有后端开发都阻塞在完整光流上。

## 10. 可选 R1：循环图整合研究分支

**启动条件：** 简单局部／自适应池化存在明确限制，且有足够可配对数据和资源比较学习方法。

### 10.1 实施路径

1. 首轮固定 Python V1，在标准化特征上增加独立整合模块；不要同时重新训练前端。
2. 每个低分辨率空间位置作为节点，保留该位置的多通道运动特征。仅保留一个角度可能丢失歧义与多峰信息。
3. 用特征映射及相似性构建连接，明确空间限制、零特征处理、自连接、对称性与归一化。
4. 先比较一次图传播与不传播；再加入带门控／残差的迭代更新，扫描少量迭代次数。
5. 使用简单读出及可得监督训练。光流真值用于运动估计；航向真值用于航向任务。使用伪标签必须记录来源与局限。
6. 比较固定前端的非循环自适应池化、图传播与循环图变体，区分特征学习和循环本身的收益。

2025 年模型的特征相似图加卷积 GRU 是受训练的整体。简化传播只是项目变体，不能继承其论文表现。

### 10.2 计算与时序要求

全连接图对 N 个节点需要约 O(N²) 的连接存储。先评估节点数、低分辨率网格和批量内存；必要时使用受限邻域或稀疏连接，并说明偏离原模型的地方。

单个输入上的多次推断与跨视频帧的状态记忆分别管理、计时。不能把迭代次数直接换成人类反应时间。保留与 MSTd 时间状态的独立开关，防止重复积累造成跟踪滞后。

## 11. 可选 R2：高阶运动与可学习 V1

### 11.1 先证明需求

建立配对实验：几何、相机轨迹、物体运动相同，只改变材质／光学扰动；再增加相机静止但有闪烁、高光或折射变化的负对照。

分别统计局部方向错误、航向偏差和有效误报。若一阶模型已满足目标，暂不加入高阶模块。

廉价的噪声、对比度包络或闪烁刺激只作为初筛；它们不能替代物理渲染的非朗伯材质实验，也不能宣称全部是纯二阶运动。

### 11.2 加入方法

1. 保留原始图像序列接口，新增并行的非线性预处理通路，再经过运动能量约束，与一阶特征融合。
2. 可先评估简单的滤波—整流—滤波思路；如采用论文式 3D CNN，在独立变体中训练，明确输入、窗口与通道。
3. 原始连续 84 通道仍保留为一阶基线。不能仅在已压缩的八方向输出末端添加 MLP，就声称等价于图像预处理通路。
4. 使用配对漫反射／非朗伯训练集，比较“一阶／双通路 × 两种训练环境”，分离架构和数据贡献。
5. 按完整场景、物体／材质组合及轨迹划分开发与测试，检查跨材质、跨场景泛化。
6. 二阶运动刺激作为泛化验证；主验收仍是所需自运动任务。人类相关性提高不自动等于几何估计更准确。

### 11.3 可学习 V1 单独立项

仅在固定前端出现明确适用范围限制时，再开放频率、方向、带宽、时间常数等参数；使用物理可解释约束和独立配置。

依次比较固定 V1、固定 V1 加学习整合、可学习 V1 加同一整合，不能同时修改所有层后只报告总结果。

论文的一阶输入使用 11 帧并监督序列中间时刻，包含相对于目标时刻的后续帧。在线版本使用因果窗口或显式等待并报告延迟；不能直接将其离线性能当作实时性能。高阶更长窗口也需同样核查。

## 12. 统一验收与保留／停止规则

### 12.1 对照原则

- 同一输入、内参、处理分辨率、有效 ROI、评价时间段及场景划分。
- 主要对照先冻结上下游参数，定位新增机制贡献；联合调参作为后续独立实验，记录各方法预算。
- 独立场景／轨迹为统计单位，不能将大量相关帧当作同等数量的独立重复。
- 分开报告场景随机性、脉冲随机性和训练随机性。学习实验视资源采用重复训练，不用单次最好结果代表稳定收益。
- 保留逐帧结果、序列级指标及场景级差异；有足够独立样本时报告配对差异与置信区间。
- 启动、停止和切换瞬态单独评价，不逐条挑选最有利稳态窗口。

### 12.2 何时保留机制

在预先定义的目标条件与独立测试上改善主要任务指标，且覆盖率、误报、延迟和计算代价处于约定范围。局部指标解释改善发生在哪里。

若只改善边界局部指标，应如实记录；可以作为局部表征研究成果，但尚不能宣称改善自运动。

### 12.3 何时暂停该增强并回到主线

- 简单基线同等有效，而新增机制明显更复杂。
- 误差改善来自降低覆盖率、增大等待时间或测试集调参。
- 只在训练材质／场景有效，独立测试没有收益。
- 无法定位改善来源，或源迁移与结构改进混在同一个版本中。

保留实验结果和失败分析，继续推进适用范围内的自运动目标，不为了“用上论文”而强行保留机制。

## 13. 开发 agent 的交付约定

### 13.1 每项变更的最小交付

1. 清楚的假设、触发现象、所改模块及默认关闭的变体开关。
2. 同输入冻结基线的运行方式和独立输出目录。
3. 有意义的数值／状态回归检查，以及与所研究机制对应的任务实验；不编写只重复实现逻辑的测试凑数量。
4. 逐帧输出和序列汇总；模型／数据／配置版本、时间定义和单位。
5. 实验报告：实际执行内容、通过／失败／未验证项、结论、限制和下一步。

建议使用 `experiments/scratch/manual__paper_roadmap__r01/<experiment_id>/` 存放产物，实验目录唯一且不覆盖。不强制更换现有记录格式，优先扩展已有工具。

建议实验记录包含：

```text
实验ID、父基线ID、模型变体、代码与配置版本
输入及真值来源／哈希、场景与轨迹划分、随机种子
分辨率与相机参数、帧时间、窗口、重置与因果约定
逐阶段输出及单位、评价ROI、门限与预热规则
局部指标、航向指标、覆盖率、误报、延迟、耗时和内存
实际运行环境、未完成验证、保留或暂停机制的依据
```

### 13.2 建议任务包顺序

| 任务包 | 内容 | 依赖 |
| --- | --- | --- |
| T0 | 审查并复用 Python V1 迁移工具；整理实际连续响应与后端对照报告 | 当前即可开始；外部 CUDA 未执行时明确记录 |
| T1 | 完善静态、停止、切换、多速度和二维线索的局部诊断 | 数值路径可运行；不能跳过迁移差异定位 |
| T2 | 理想方向证据与实际图像的纯平移逐序列评价 | 理想输入部分可与 T0 并行；端到端结论依赖 T0/T1 |
| T3 | 动态干扰数据与方窗／高斯／保边界池化对照 | 冻结 T2 基线 |
| T4 | 尺度核验、可选速度表征与一般自运动后端 | 按 T1/T3 诊断确定所需项 |
| T5 | 可选循环图整合研究 | 简单机制不足且数据／资源支持 |
| T6 | 可选材质对照、高阶通路或可学习 V1 | 明确光学扰动失效及训练评价条件 |

任务包完成后先依据报告决定下一项，不一次性实现 T0–T6。源迁移修复可以在 T0 内完成；算法增强使用独立配置。

### 13.3 可直接交给开发 agent 的首轮指令

> 阅读本文，以及 `PYTHON_V1_SERVER.md` 和当前代码。先盘点已完成的 Python V1、连续记录、张量后端和实际实验报告，复用现有实现，不覆盖并行改动。首轮执行 T0，并完成 T1/T2 所需评价工具中不依赖外部数据的部分。固定现有投影与 MT/MSTd 参数，分开记录 NumPy/PyTorch 一致性、实际 C++ 连续响应一致性和任务有效性；核查尺度、边界、历史与时序语义。输出迁移报告与下一批最小实验清单。当前不要加入图网络、可学习 V1 或高阶通路，也不要把未运行的 CUDA 实验或人工输入测试写成端到端通过。基础检查满足后，继续完成纯平移基线；根据具体失效再按本文选择单项增强。

## 14. 用户把握方向时只需关注的决策

每轮报告应能回答：

1. 当前要解决的是迁移错误、局部方向问题，还是自运动整合问题？
2. 新增机制针对哪个可重复现象，为什么现有简单方法不足？
3. 收益体现在哪个任务指标，是否付出了覆盖率或延迟代价？
4. 是否在独立场景成立，下一步继续主线还是值得扩大该分支？

当前决定：先完成统一 Python 基线与纯平移验证。两篇论文作为可检验机制的来源，随问题逐步引入；不把完整复现两篇论文作为自运动目标的前置工程。
