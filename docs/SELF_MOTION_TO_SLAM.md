# 自运动估计到 SLAM 位姿估计：分阶段实施方案

日期：2026-10-25（Asia/Shanghai）。本方案记录当前约定；此前技术方案的纯平移范围描述当前基线，本方案补充后续路线。

## 1. 目标与边界

当前先完成可解释的 V1–MT–MSTd 自运动模型，再研究如何将其接入 SLAM。暂不同时开发完整建图、回环和后端优化。

自运动估计是广义任务，可以包含位姿估计。本项目当前将其阶段输出定义为：平移方向，以及后续扩展的旋转相关参数、曲率、转向符号和视线相对轨迹切线偏角。

完整相对位姿要求每个图像时间段的旋转增量 ΔR 和平移增量 Δt；按统一坐标约定组合这些增量，才能得到轨迹。平移方向不等于相机姿态角，识别左右转也不等于恢复旋转量和位移量。

## 2. 当前实现

视频图像 → 现有 C++/CUDA V1 → 84 通道 SpikeMonitor DAT → Python 28→8 方向投影与尺度汇总 → MT 局部池化／归一化 → MSTd 径向膨胀模板与简化时间竞争 → 水平平移航向。

- V1 的 28 类时空滤波器 × 3 尺度不等于 28 个运动方向或三个已校准速度通道。
- MT 当前输出方向群体向量，幅值是方向证据，不能直接解释为像素速度。
- 默认航向为 −20°～20°、5°间隔，仅膨胀模板；尚无收缩／旋转／曲率读出。
- 动力学为 CD 启发的简化实现，不是原论文逐式复现。
- 真实历史 DAT 已完成接口验证；新刺激的真实方向校准与航向精度仍需采集验证。

## 3. 阶段 A：V1→MT 基础方向校准（当前任务）

输入为 45°间隔的八方向光栅，补充平移纹理、静态和多速度条件。

观察八通道投影调谐、实际 MT 群体方向、方向误差、空间／时间一致性、启动与切换延迟、黑场及静态响应。邻近方向共同活动可以接受，不要求单一通道独占。

连续光栅按 CSV 分段，在每段排除启动窗口并保留逐帧结果。黑场没有运动标签，也不清零 V1 历史。连续采集与独立条件重置采集分别记录。

验收：输入与响应配对明确，尺寸／时间／通道正确，八方向可区分，无固定符号翻转；工程阈值只是筛查，需结合背景和时间曲线。光栅存在孔径歧义，应再用纹理复核。

部署和命令见 [Ubuntu 20.04 方向测试指南](UBUNTU20_MT_GRATING.md)。本轮不以 MSTd 对整幅平移光栅的航向输出作为验收依据。

## 4. 阶段 B：纯平移自运动基线

在静态三维点云／地面中移动相机，渲染二维图像 DAT。V1 输入是图像，不是三维坐标或箭头图。

先用理想方向证据独立检查后端，再接真实 V1 响应，分离前端与后端误差。优先条件为静止、点云前进、地面前进、相机朝向固定的左右偏移 ±10°平移；随后加入模板网格之外的角度与独立场景种子。

输出与验收：逐帧航向、模板分数、群体活动、有效标志；统计角度误差、分位数、有效覆盖率、静止误报、启动延迟。真实响应未到位时不能报告精度。

## 5. 阶段 C：时间竞争与鲁棒性

加入独立运动物体、遮挡、噪声、弱纹理和真实航向变化。固定相同输入，比较瞬时匹配、普通时间平滑和时间竞争。

同时评价误差、波动、恢复时间和真实变化的跟踪延迟，避免将迟钝解释为稳定。保留原始基线和各次配置。

## 6. 阶段 D：一般自运动参数

逐步增加后退、原地 yaw、平移加旋转、左右圆弧、不同半径、不同视线偏角及连续运动变化。

扩展收缩、旋转、螺旋、地面和半视场模板，利用多模式群体活动解码连续参数。先比较可解释的线性／小网络读出，必要时再研究 ESN 或学习型表征。

转向符号是中间指标；最终尽量估计角速度、曲率等连续量。单一螺旋模板不直接等价于车辆左／右转。已知相机高度／地面约束等尺度假设必须显式记录，仿真真值仅作监督与评价。

训练、验证、测试按独立场景和完整轨迹划分，不能随机拆相邻帧。当前未实现的功能须逐项验证后再认定完成。

## 7. 阶段 E：接入位姿估计与 SLAM

自运动模型验证后，确定其在前端中的角色：

1. 提供平移方向／旋转约束或初值，与几何位姿求解联合工作。
2. 或从群体活动直接解码运动参数，再与尺度、深度及必要传感器约束融合。

对于车辆，可先在明确的平面运动假设下输出 Δx、Δz、Δyaw，再扩展六自由度 ΔR、Δt。需要补齐旋转估计、位移大小、连续跟踪、不确定性与失效检测。

单目未知场景存在尺度歧义；选择未知尺度的单目里程计，或采用双目／RGB-D、地面及相机高度、IMU、轮速等约束。IMU 不会自动消除尺度问题，需标定、同步和满足可观测条件。

保留图像与特征、相机内参、时间戳、完整运动证据和质量指标，避免未来只能拿到一个航向角。当前 MT 归一化不能保证保存速度信息，需要额外研究幅度／速度编码或几何分支。

最终输出约定：时间段、坐标系、ΔR、Δt、尺度状态、有效性和约束权重／协方差。接入后端前完成坐标和时延核对。

评价逐步升级为相对位姿误差、累计轨迹误差、旋转／尺度漂移、运行延迟与失败率；有尺度和无尺度评价分别报告。建图与回环属于 SLAM 系统集成阶段，不是当前八方向模型测试任务。

## 8. 文献对应

- [ViSTARS 2009](https://sites.bu.edu/steveg/files/2016/06/BroGroMin2009.pdf)：分层视觉运动到航向。
- [Layton 与 Fajen 2016](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004942)：MSTd 时间竞争与动态干扰下的航向稳定性。
- [ARTFLOW 2021](https://www.mdpi.com/1424-8220/21/24/8217)：学习运动模板，从 MSTd 活动读出平移方向与旋转相关参数。
- [Layton 等 2022](https://pubmed.ncbi.nlm.nih.gov/35580573/)：多模式群体和学习型解码，估计曲率、转向符号、视线相对切线偏角。

这些是机制与参数估计的参考，不应直接等同于本项目已经具有完整米制六自由度视觉里程计。
