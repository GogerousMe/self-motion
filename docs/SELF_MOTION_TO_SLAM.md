# V1–MT–MSTd 后续开发与自运动验收路线

更新于 2026-11-17（北京时间）。这是项目后续规划的主入口。各阶段的实现细节、运行命令和实验结果见文末索引。

## 1. 当前目标与实际进度

先完成**限定运动范围内的视觉航向估计**。模型从连续图像和相机标定出发，估计前向平移在相机坐标系中的水平偏角，并输出有效性、估计对应的时间和结果可用时间。稳定性、跟踪速度与局部反馈的收益均以独立图像序列验证。

相机坐标采用右方为 \(X\)、前方为 \(Z\)。水平平移航向为 \(\alpha_x=\operatorname{atan2}(T_x,T_z)\)。例如 \(+10^\circ\) 表示移动方向相对镜头正前方偏右 \(10^\circ\)。相机 yaw 描述镜头朝向的转动，需要单独估计。车辆左转时，瞬时平移方向仍可能接近镜头正前方。

当前主链路为 **图像 → Python MotionEnergy V1 → 脉冲 MT → 连续活动 MSTd → 水平航向**。默认九个模板覆盖 \(-20^\circ\) 至 \(+20^\circ\)，可在相邻模板之间做局部插值。现有 MT 向量表示方向证据，幅值尚未标定为像素速度。项目已具备航向读出、有效性判据和反馈接收接口。航向驱动的 MSTd→MT 控制器、图像旋转估计、速度及相对位姿仍待开发或验证。 [统一运行说明](MODEL_RUN.md) · [四阶段回路设计](MT_MSTD_CIRCUIT_DEVELOPMENT_V01.md)

**真实图像航向尚未通过验收。** 2026-11-17 的审计核对了 KITTI 01、04、08 三段共 36 个配置运行。以原 MT 和参考 MSTd 动力学为例，三段正式有效帧分别为 0/60、56/60、57/60，三段的全窗口候选误差都高于恒输出 0° 的参照。三个片段的航向都接近正前方。现有证据足以启动可开关的反馈机制研究，真实图像航向的精度、左右方向覆盖与切换验证仍需继续。完整记录在实验索引中的 `20261117__kitti_stage4_readiness__v01`。 [已有 KITTI 输入与时序说明](KITTI_TEMPORAL_REAL_INPUTS_V01.md) · [实验索引](../experiments/registry.csv)

## 2. 四阶段机制与验收

| 阶段 | 作用与目标 | 当前状态及通过依据 |
| --- | --- | --- |
| **第一阶段 · MT 空间整合** | 同方向运动在邻近位置互相支持，降低局部噪声，同时保留运动边界。 | 回路已实现。与原 MT 配对比较局部方向误差、有效覆盖率和边界混合，再核对独立真实片段的航向收益。已有 KITTI 结果的收益较小且不一致。 |
| **第二阶段 · MT 方向竞争** | 压低弱干扰方向，保留有证据支持的相邻方向和多重运动。 | 竞争抑制回路已实现。已有矩阵中仅竞争组有 31/32 个运动条件的局部误差高于基线。当前主对照采用原 MT 与仅空间整合分支，方向竞争保留为独立研究项。用单向、通道之间的斜向、弱干扰和两层运动联合验收。 |
| **第三阶段 · MSTd 时间竞争** | 维持稳定航向并跟踪真实变化，短时扰动后可恢复。 | 已有连续活动方程、自激励与群间抑制，本轮已开放配置和消融，并完成理想输入及 KITTI 对照。真实动态航向的时序收益仍待验证。 |
| **第四阶段 · MSTd→MT 反馈** | 把全局航向映射为各位置、各方向的调节，在局部证据弱或含噪时改善方向估计。 | 延迟传输和 MT 接收接口已存在。航向控制器及闭环收益待验证。先做关闭反馈、限幅的额外电导和输入乘增益对照。 |

### 第三阶段 · 同时验收稳定性与跟踪

用长时间保持、非零航向阶跃（例如 \(-10^\circ\) → \(0^\circ\) → \(+10^\circ\)）、缓慢扫动、短时遮挡和停止五类时间窗口。保持期看误差与抖动，变化期看跟踪延迟，干扰结束后看恢复时间，停止后看活动衰减和有效输出是否及时撤回。逐帧保留模板得分、群体活动、候选角及正式输出。

固定相同的 MT 输入、模板、有效性判据和读出，比较瞬时匹配、普通时间平滑、无递归的输入动力学与完整时间竞争。自激励、群间抑制与时间常数可分别消融。平滑与竞争用相近迟滞或误差—延迟曲线比较。已有理想输入协议可作为机制回归，最终使用连续真实图像验证。 [第三阶段实现与执行入口](MSTD_TEMPORAL_STAGE3_V01.md)

### 第四阶段 · 调节局部方向并检查纠错

利用模型自身的 MSTd 航向活动分布和径向模板，生成位置 × 八方向的支持权重。比如相机正前进时，左侧画面的左移通道与右侧画面的右移通道分别获得支持。采用因果延迟、幅度上限和依据当前证据的有效性门控。门控关闭时停止产生新的反馈驱动，已有电导按设定时间常数衰减。初始一步延迟以实际神经时间步解释，反馈强度和时间参数列入对照。

首轮固定 MSTd 参考动力学，先在原 MT 与仅空间分支上比较以下条件：

1. **关闭反馈或反馈增益为零。** 检查基线复现。
2. **额外电导。** 将连续航向支持转换成延迟到达的突触电导增量，作用到脉冲 MT 的膜电位更新。沿用现有设计与接收接口。
3. **输入乘增益。** 使用同一支持图调节 MT 已有的视觉兴奋输入，作为 ViSTARS 式的机制对照。分别记录两种调节的单位、时序和作用位置。

机制检查记录逐神经时间步的门控、反馈驱动、电导和放电。任务检查覆盖弱局部证据、短时遮挡、静止、方向变化、独立运动物体，以及**人为给出错误初始航向后能否恢复**。比较各组的局部方向误差、航向误差、覆盖率、静止误报、切换延迟和恢复时间。用已冻结的反馈关闭基线评估净收益。 [反馈映射与工程设计，第 7 节](MT_MSTD_CIRCUIT_DEVELOPMENT_V01.md) · [ViSTARS，式（5.1）](https://sites.bu.edu/steveg/files/2016/06/BroGroMin2009.pdf)

### 四阶段通过后可以报告什么

四阶段机制都经过相应对照、且联合配置通过独立图像输入的端到端验收后，可报告**在已验证运动范围和干扰条件下，具备时间稳定性和反馈调节能力的视觉航向估计模型**。阶段成果应明确支持的方向、速度范围和场景条件，以及有效输出的时间和覆盖率。

机制实现、消融结果、联合模型验收分别记录。若某个候选机制未达到增益和延迟目标，保留它的独立对照，基线验收仍可推进。阶段结论按最终启用且有独立证据支持的机制撰写。

## 3. 真实视频航向验收

| 测试组 | 选段与验收重点 |
| --- | --- |
| **水平平移** | 按相机坐标航向真值选近零、左偏、右偏，覆盖多个非零角度和模板网格外角度。前向且低旋转的片段用于确定当前模型的适用范围。报告各角度组实际样本数与覆盖缺口。 |
| **连续变化与干扰** | 覆盖启停、加减速、航向变化、左右弯道、并线、弱纹理、短时遮挡及独立运动物体。按航向和旋转率分别分组，旋转明显的片段在现阶段用于压力测试。 |
| **静止与范围外** | 使用实际停车、近纯旋转、低位移、倒车、大侧移和超模板角度的图像。静止或近纯旋转时无法定义可靠的平移方向，重点评价误报及退出时间。 |
| **泛化** | 测试场景、轨迹与调参阶段分开。改变纹理、深度结构和运动速度，记录独立片段与随机种子。随机纹理、光栅和理想方向场继续用于诊断与回归。 |

数据优先级：

1. **KITTI Odometry 00–10。** 复用现有真值筛选工具，增加航向角、旋转率、速度和场景分桶。01、04、08 保留为近直行回归。 [本项目选段工具](../tools/screen_real_heading_sources.py) · [KITTI 官方基准](https://www.cvlibs.net/datasets/kitti/eval_odometry.php)
2. **nuScenes。** 使用同一前视相机的连续图像、曝光时间、对应车体位姿与相机外参，做冻结配置后的跨数据集评价。车体定位提供平面运动参考。 [采集说明](https://www.nuscenes.org/data-format) · [数据格式](https://github.com/nutonomy/nuscenes-devkit/blob/master/docs/schema_nuscenes.md)
3. **TUM RGB-D 或有同步位姿真值的受控实拍。** 用 TUM 的 `freiburg1_xyz` 与 `freiburg1_rpy` 辅助检查平移和旋转。若道路数据缺少非零低旋转样本，用相机朝向固定的真实场地斜向移动补齐。 [TUM 官方序列说明](https://webshare.cvg.cit.tum.de/g/rgbd/dataset/)

同一实验比较恒输出 0°、反馈关闭基线和候选模型。报告全窗口候选 MAE、正式输出 MAE、共同有效帧误差、偏差、P95、有效覆盖率、静止误报、抖动与跟踪／恢复时间。指标按独立片段和场景组汇总。真值仅用于选段和离线评价，明确位姿差分窗口；评估快速变化时同步查看短窗口参考。帧间隔、原始时间戳、裁剪缩放和相机内参随实验保存。先在开发集确定验收阈值，再冻结后跑独立测试。 [真实输入的时间对齐示例](KITTI_TEMPORAL_REAL_INPUTS_V01.md)

如果真实视频表现落后于参照，先同时查看原图、V1 投影、MT 局部方向场和 MSTd 得分。可在少量失败片段做分辨率配对，或用已知运动方向场替换 MT 输入来定位误差。光流算法结果可用作诊断参考，有独立真值时再报告局部方向精度。

## 4. 从航向到一般自运动与相对位姿

| 开发目标 | 输出与所需条件 | 验收 |
| --- | --- | --- |
| **速度表征** | 先估图像运动方向与幅值，输出像素/秒或有明确帧间隔的像素/帧。对不同速度、纹理频率、方向和帧间隔标定调谐，保留速度相关活动及未归一化证据。 | 在未见速度和纹理上验证速度误差、方向误差与覆盖率。用有位移真值的图像检查幅值。MT 归一化向量的幅值和放电率需要经过标定才能参与速度读出。 |
| **旋转估计与平移–旋转分离** | 先同时输出水平平移航向和带符号的 yaw 角速度。比较多模式模板读出与几何分支，必要时用已知旋转做解耦上界诊断。随后研究后退、侧移、垂直方向及俯仰和横滚。 | 依次测试固定朝向的斜向平移、绕相机中心的纯 yaw、平移与 yaw 混合、左右圆弧。纯 yaw 重点查平移误报，混合条件同时评价方向与角速度。 |
| **米制速度与位移** | 结合双目、RGB-D、已知相机高度及适用的地面模型、轮速，或经标定、同步且满足可观测条件的视觉惯性融合。记录速度单位、尺度来源和尺度有效状态。 | 测米/秒与每段位移误差，检查速度变化、低位移及尺度漂移。无米制尺度的单目结果以旋转和平移方向或无尺度轨迹报告。 |
| **相对位姿和轨迹** | 对车辆先在平面假设下估计起始相机坐标系中的 \(\Delta x,\Delta z,\Delta\mathrm{yaw}\)。统一每段运动的参考坐标与时间区间，按顺序复合成轨迹。再扩展到三维旋转 \(\Delta R\) 与三维平移 \(\Delta\mathbf p\)。 | 输出时间起止、估计可用时间、坐标系、旋转与平移增量、尺度状态、有效性和可验证的权重或不确定性。评价相对位姿误差、绝对轨迹误差、漂移与失败率，说明对齐方式和尺度条件。 |
| **SLAM 前端集成** | 先比较让 MSTd 提供航向／旋转先验或质量权重，与直接从群体活动读出运动参数两条路径。通过位姿验收后，再决定建图、回环与图优化的集成范围。 | 与几何前端及融合前端作同输入对照，验证误差、可用率、失效恢复和延迟。 |

速度表征和 yaw 可以在航向基线冻结后并行研究。车辆真实转弯优先解决平移与 yaw 的相互混淆。米制曲率和位移需要明确尺度。若同时研究道路曲率与视线偏角，建议用不同转弯半径、速度与相机朝向的独立轨迹做解耦验证。已有后退、纯 yaw 和圆弧刺激可先用于机制测试。 [自运动刺激说明](SELFMOTION_STIMULI.md) · [单目视觉惯性尺度实例](https://arxiv.org/abs/1708.03852) · [里程计轨迹评价与对齐](https://rpg.ifi.uzh.ch/docs/IROS18_Zhang.pdf) · [曲线自运动模型](https://pubmed.ncbi.nlm.nih.gov/35580573/)

## 5. 下一轮执行顺序

1. **冻结并扩大真实航向基线。** 固定当前原 MT 和仅空间 MT 的配置，先统计 KITTI 的真值角度覆盖及缺口。保留三段现有回归，补齐非零角、场景干扰与拒识测试。输出每个测试组的片段列表、筛选条件、真值与时间定义。
2. **在同一基线上推进第四阶段受控对照。** 先完成反馈关闭复现、延迟、门控、限幅和纠错检查。随后用独立真实图像检验局部及航向收益。方向竞争继续以单独开关跟踪，结果支持时再考虑联合运行。
3. **完成水平航向阶段验收。** 冻结待验收配置，按第 3 节汇总误差、覆盖率、误报、时延和可复现范围。开发结果和独立测试结果分别登记。
4. **增加速度表征与 yaw 分离。** 先核对静止、纯平移和纯旋转，再验证混合运动。根据所选深度或尺度来源进入米制运动和相对位姿。
5. **累计并评价轨迹。** 平面相对位姿达到约定指标后，开展三维位姿与 SLAM 前端对照。
