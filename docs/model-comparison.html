01 / 方案定位

保留 V1，以全局光流编码和时间竞争估计自运动

我们的主线：现有 V1 → 校准后的 MT 局部运动 → MSTd 全局模板与时间竞争 → 自运动参数读出。

主线 · Layton 2016

以 MSTd 时间积累与递归竞争为机制依据，研究航向稳定性。

辅助 · ViSTARS 2009

参考分层运动整合、归一化及 MT–MSTd 一致性反馈。

扩展 · Layton 2022

引入多模式模板和群体解码，研究曲率、转向与视线偏角。

状态约定：“已实现”只说明已有代码；“待验证”说明任务性能尚未建立；“计划”表示尚未接入主线。当前模型是组合参考原型，不能称为上述论文的完整复现。

03 / 当前 Python 主线

几何模板匹配＋时间竞争，直接服务平移航向

已有代码真实端到端精度待验证保留修改版 V1，通过离线 DAT 接入 Python 后端。

纯平移且相机不旋转时，静态场景光流的扩张中心与平移方向相关。当前模型为不同候选扩张中心构建单位方向场，与 MT 运动向量进行归一化点积匹配，再通过时间竞争选出候选航向。

MT 当前采用局部方窗池化、除法归一化和方向群体向量；其输出是运动方向证据，不能直接解释为 px/s 或米/秒。有效标志是工程门限，尚不是经过校准的正确概率。

07 / 开发路线与预期效果

先证明平移航向，再验证鲁棒性，最后扩展曲线运动

  1. 校准 V1→MT。用单向运动刺激检查 8 方向输出、方向符号、通道排列、增益与时间延迟。通过后才能解释后端结果。
  2. 建立平移航向基线。测试静态、正前进、左右斜向平移；加入模板网格之外的航向，避免只测 0°、±10° 等模板中心。
  3. 检验竞争是否带来收益。比较瞬时匹配、普通时间平滑、时间竞争；测动态物体、遮挡与噪声下的误差和恢复时间，同时检查真实转向的跟踪延迟。
  4. 扩展多模式与解码器。加入后退、旋转与曲线运动；利用群体响应估计转向、曲率及视线偏角。米制曲率需明确尺度或场景约束。
  5. 开展同输入对照与真实场景验证。为 STDP MST 配置一致的输入和航向读出；按独立场景／完整轨迹划分训练测试，评估泛化，再决定是否引入 ESN 或其他融合。
