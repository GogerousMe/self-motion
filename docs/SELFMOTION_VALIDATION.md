# 自运动刺激生成验证（2026-10-19）

## 几何与渲染

新实现基于静态三维点／地面和针孔投影，相机运动后重新投影，未用箭头或预制光流图冒充视频。
几何测试覆盖：前进膨胀、后退收缩、相机右yaw导致场景向左、圆弧轨迹半径与速度、注视偏角、静止无光流、地面在地平线下方，以及同ID点精确相邻帧位移。
生成器同时记录已知相机内参、运动参数、逐帧相机状态和稀疏光流。

## 实际执行

- 25项unittest通过，包括原有回归、5项自运动测试以及自运动清单／选定子集采集编排测试。
- 生成14个条件，每段80帧、80×80、20fps，250个点。
- 生成14个AVI、14个输入DAT、14个逐帧真值JSONL及预览／元数据。
- 用ffmpeg逐个解码14个FFV1 AVI，全部1120帧灰度字节与配套DAT逐像素一致。
- 每帧真值含250点投影；静止控制的点位移为零。
- 已检查地面前进中间帧图像，地面点位于下半视野，无箭头／文字叠加。

## 结论边界

这些结果验证图像生成、几何符号、编码一致性和采集编排，不是实际CARLsim V1神经响应，也不是自运动识别精度。
Python MSTd后端仍为膨胀模板基线，收缩、旋转与曲率解码尚未实现。
新条件需由用户在Linux手动采集，再返回响应进行评估。
参数调整适配当前80×80/50ms工程，与论文512×512/30fps并不相同。
