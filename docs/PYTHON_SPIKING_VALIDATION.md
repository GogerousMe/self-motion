32×32初轮整模型初始化约0.004–0.006秒；最终八方向复验40帧CPU运行约17–23秒，包含V1、细步MSTd适配、状态和原始脉冲记录。并行测试/系统负载会影响耗时。
另实际初始化80×80整模型约0.077秒（outputs/python_spiking_init80.json），仅初始化，没有运行80×80视频。
这里没有CARLsim全配对构网，不能把这些数字当作与旧模型严格等价的加速比，也不宣称实时处理。
