## 1. 目标与范围

建立从视觉运动证据，经 MT 局部运动群体编码、MSTd 全局模式编码，输出自运动参数的可解释系统。
保留既有 V1 资产，不要求整个模型重写或迁回 CARLsim。以 Python 活动率模型为主线，脉冲回放与脉冲动力学是可选研究扩展。

首阶段限定固定相机的纯平移，输出相机坐标下的平移方位角和有效性。
第二阶段在平面运动及明确相机几何条件下研究旋转、左右转、曲率、视线相对轨迹切线偏角。
第三阶段评估真实视频、多场景泛化及 IMU／轮速辅助。完整 6DoF 位姿、绝对速度、长期轨迹、动态分割和避障不属于首阶段承诺。
单目速度／深度尺度歧义必须显式处理。米制曲率依赖已知高度、几何约束或其他尺度来源。
静止时平移方向无定义；低纹理、弱运动和严重遮挡应允许无效输出。

## 3. 总体架构

```text
视频 + 相机参数
  → C++ MotionEnergy/V1（保留）
  → 标准化离线文件与编码适配器
  → Python MT（方向／速度编码、空间池化、归一化）
  → Python MSTd（模板匹配、时间积累、竞争）
  → 解码器（先峰值／线性，再小网络／ESN）
  → 自运动参数 + 有效标志 + 可靠性指标
```

算法分层接受统一输入，允许用解析光流生成的运动群体响应绕过 V1，分别定位前端和后端误差。
连续输入必须保留历史状态；仅在独立序列边界 reset。记录预热区间，避免将滤波器启动瞬态当作正常表现。
固定离线 V1 不支持依赖后端的 V1 反馈。需要此反馈时再联合运行；MT–MSTd 内部反馈可以保留在 Python 后端。

## 5. 各层设计

### 5.1 MT

目标表示 R[t,s,d,y,x]，s 表示经校准的速度偏好，d 为方向，保留视网膜空间结构。
当前首版仅 R[t,d,y,x]，无速度选择性声明。
首版采用局部方窗池化、除法归一化以及方向群体向量。群体向量是运动方向证据，不是 px/s 速度。
完整版本比较高斯／方向拉长池化、跨方向竞争、多速度通道及噪声抑制；使用光栅、随机点、运动边界测试。
孔径问题不能由当前简单池化自动宣称已解决，需单独实验。

### 5.2 MSTd

先以不同膨胀中心的径向模板建立纯平移基线。
模板中心由相机内参映射到角度；alpha_x=atan((u-cx)/fx)、alpha_y=atan((v-cy)/fy)，是投影方位角，不是 Euler 姿态。
首版模板匹配为 MT 群体向量与局部模板单位方向的归一化点积，负分数整流到零。

当前参考动力学（工程简化式，非论文原式）：

```text
f(a)=a²/(0.25+a²)
tau * da_i/dt = -a_i + (1-a_i)*(gain*score_i + recurrent_gain*f(a_i))
                - a_i*inhibition*mean_{j≠i}(f(a_j))
```

用小步长显式积分，每步同时更新，数值活动限制在 [0,1]。步长收敛测试是必要条件；不能以截断代替稳定性验证。
后续将原论文分流动力学、空间竞争核、时间积累分别实现并与此基线比较。
纯平移模板对旋转混合不充分。扩展径向、收缩、螺旋、圆周、地面及半视场模板后，再训练曲线解码器。
模板形式是特征基，不把单个螺旋模板直接等同真实曲线路径。不能把所有转动光流消除后又要求解码曲率。

### 5.3 解码

纯平移先 argmax／峰值插值；再比较岭回归与小型前馈网络。
保留完整空间活动分布及模板类型分布，按任务决定是否池化。
ESN 仅在证明额外记忆改善误差和延迟后引入；避免与 MSTd 时间积累重复造成滞后。
margin、活动熵、MT 方向一致性可作可靠性特征，未经验证不能解释为正确概率。

## 8. 数据集与验收

层级 A：已知方向／速度光栅和随机点，验证 V1 调谐与通道顺序。
层级 B：解析相机运动和深度产生的光流，验证几何后端。
层级 C：独立运动物体、遮挡、弱纹理、噪声、旋转和平移变化。
层级 D：拟真仿真视频与真实带真值序列，验证端到端。
合成方向响应仅作接口及 smoke test，不能代替上述物理视频验证。

训练／验证／测试按独立完整轨迹、场景划分，禁止随机拆相邻帧。
指标：方向角误差、误差分位数、有效覆盖率、误报有效率、转向 F1、曲率误差、响应延迟、遮挡恢复时间、墙钟耗时与内存。
比较：模板匹配、匹配+普通平滑、匹配+竞争、竞争+不同解码器；同一输入公平比较。
必须检查真实转向能否及时跟踪，防止把滞后误认为鲁棒。
性能与准确率阈值在获得 V1 基线和设备信息后设定；当前不预先承诺论文精度或实时性。

## 10. 当前风险与控制

编码错配：严格协议拒绝 raw_filter 冒充 direction_rates；核对真实链接库。
坐标错误：x 右、y 下、方向角图像坐标正向为顺时针；摄像机运动号需用可控刺激验证。
速度尺度不足：首版不输出物理速度；增加速度通道必须标定。
归一化丢失证据：保留 MT 一致性及有效门限；后续保留幅度分支研究低对比度。
竞争锁定：强干扰和真实转向分别测试。
规模：避免 Python 神经元两两循环与全连接巨型矩阵；当前小模型验证后向量化、分批或稀疏化。
原型与复现混淆：每个输出保存 model 标识，文档明确已实现与未实现内容。
