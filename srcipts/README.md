# 连续八方向黑白光栅（MATLAB）

打开本目录的 `makeGrating.m`，在 MATLAB 中点击 Run。脚本调用同目录的 `generateGratingSequence.m`，从公式生成新刺激，不读取已有 DAT，也不依赖外部 GratingStim 类。

所有速度、所有方向与黑场都写入同一个 `all_stimuli.dat`。默认速度为 `[1.5 0.5 1 2]` 像素/帧，严格按照列表顺序排列。不会读取或覆盖旧文件。

默认序列：

```text
速度1.5：0°光栅100帧 → 全黑50帧 → 45°光栅100帧 → 全黑50帧 → … → 315°光栅100帧 → 全黑50帧
→ 速度0.5：同样的八方向和黑场
→ 速度1：同样的八方向和黑场
→ 速度2：同样的八方向和黑场
```

唯一DAT为80×80、单通道、4800帧，50ms/帧，总计240秒。每个速度/方向条件光栅5秒，黑场2.5秒。完整原速预览约4分钟，另有生成、绘图与写盘耗时。

修改入口脚本顶部参数：

| 参数 | 用途 |
|---|---|
| `cfg.Speeds = 1.5` | 仅生成一个速度的连续DAT |
| `cfg.Speeds = [1.5 0.5 1 2 0]` | 静态光栅也追加到同一DAT，共6000帧 |
| `cfg.StimulusFrames = 100` | 每方向光栅帧数 |
| `cfg.BlankFrames = 50` | 纯黑间隔帧数，所有像素为0 |
| `cfg.TrailingBlank = false` | 只取消整个文件最后的黑场，默认4750帧、237.5秒 |
| `cfg.ShowPreview = true` | 运行时可视化每一帧 |
| `cfg.PlaybackRate = 4` | 四倍速预览，不影响DAT或仿真时长 |
| `cfg.Size = [80 80]` | 图像高、宽，匹配V1实际输入 |
| `cfg.PeriodPx = 12` | 黑白完整周期，沿法线约6白+6黑 |

角度采用项目图像坐标：0右、45右下、90下、135左下、180左、225左上、270上、315右上。角度表示运动方向，条纹与运动方向垂直。每个方向开始时，相位重置为PhaseCycles，局部时间从0重新开始。

预览关闭后生成继续；预览原速属于近似墙钟播放，不是实验显示计时器。预览会在函数结束时关闭。本功能显示输入刺激，不显示神经元响应。

每次运行在 `srcipts/bw_grating_output/sequence_时间戳/` 创建新目录，包含：

- 唯一刺激文件`all_stimuli.dat`，25字节VisualStimulus v1小端文件头，type=0，按帧逐行写入；不额外翻转纵轴。
- `all_stimuli_segments.csv`，记录所有光栅和黑场的起止帧、时间、速度、方向槽位。
- `manifest.json`，记录配置、帧数、时间、文件SHA256和响应占位。

共3个文件，其中只有1个DAT，其余2个是分析用的参数与分段说明，不是额外刺激文件。

CSV帧号从1开始且两端包含；时间为`[start_ms,end_ms)`。例如第一段光栅为1–100帧、0–5000ms，第一段黑场为101–150帧、5000–7500ms，第二方向为151–250帧。黑场行的`direction_slot_deg`标记前一方向槽位，黑场自身没有运动方向。速度0的静态光栅也没有运动方向。

## 接入V1时

默认完整读取DAT内的4800帧，不要继续用80/100/1200等历史帧数常量。若实际帧时长50ms，应运行240000ms。速度1.5像素/帧对应30像素/秒；DAT本身没有帧时长字段，需使用清单并匹配C++的frameDurMs。

整个DAT的速度切换、方向切换和黑场均连续运行，不要重置；全黑输入不代表神经网络状态被清零，也不保证没有脉冲。此方案有条件间历史效应，与独立方向校准实验不同；分析应按CSV分段，排除黑场并单独评估每段启动瞬态。

这套连续清单采用独立schema，不能直接交给要求“每文件只有一个已知方向”的旧校准分析入口；后续需要按segments.csv切分同一份spk_V1.dat的时间窗。显示输入刺激通过不代表V1/MT/MSTd响应准确率通过。
